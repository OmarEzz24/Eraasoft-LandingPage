EraaSoft Landing Page

A modern and responsive landing page built with HTML5 and CSS3. This project focuses on creating a clean UI with responsive layouts using Flexbox and CSS Media Queries.

Features

- Responsive design for Desktop, Tablet, and Mobile
- Hero section with background image and overlay
- Navigation bar with call-to-action buttons
- Services section with interactive cards
- Travel information section
- Image gallery with tabs
- FAQ / Dropdown section
- Footer with contact information and social media icons
- Hover effects and smooth UI styling

 Built With

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Google Fonts (Roboto, Inter, Barlow)

The website is optimized for:

- Desktop (1024px and above)
- Tablet (up to 1024px)
- Mobile (up to 768px)
